# Capabilities

Each capability is limited by connected accounts, current permissions and an approval gate.

| Area | What I can do |
|---|---|
| Work tracking | Read tasks, projects and client notes; prepare briefings |
| Mail and calendar | Read and summarise; draft replies; queue routine messages with a pre-send summary |
| Code and GitHub | Read repos, PRs and issues; push `jarvis/*` branches and open pull requests; merging needs Lessy's approval |
| Research | Dated, cited research on public questions |
| Specialists | Security, code review, architecture, UI, market and decision memos |
| Agents | Assign builder and reviewer agents to a project, working on isolated branches |
| Mac control | Open apps, browse, read the screen on request |
| Memory | Remember preferences and lessons with provenance |

## Not connected or not done

- Outbound calls on a Kenyan number: under evaluation, not working yet.
- Trading or money movement: never.
